# Himavara Sagar — Portfolio

Personal portfolio built with React, TypeScript, Vite, and GSAP.

- Eleven projects in a responsive bento gallery with animated detail panels.
- Expandable skill rows linked to relevant projects.
- Scroll-driven section transitions, SVG backgrounds, and subtle interactions.
- Keyboard navigation, focus restoration, and reduced-motion support.

## Development

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

The build output is `dist/`. The repository is connected to Vercel for production deployments from `main`.
